2. Supabase `create-order` still contains legacy pack pricing (₹229/₹399/₹549) while current product truth declares a single ₹229 SKU.

4. Vercel order persistence path can continue after a failed Supabase write and return success with no DB id.
5. Vercel phone normalization used the first 10 digits in one path while the Supabase path uses the last 10.
6. Vercel security/CORS allows broad hosted origins while Supabase edge CORS is production-only.
7. Meta CAPI browser endpoint needs origin/rate-limit/idempotency hardening.
8. Shiprocket sync has a sequencing issue after create-or-reconcile.
9. Public content generators overlap and can overwrite one another.
10. Test/build checks are too weak for the number of server and content paths now in the project.
