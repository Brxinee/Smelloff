## 2024-05-18 - Duplicate attributes in main tag\n**Learning:** Discovered duplicate `id` and `tabindex` attributes in the `<main>` tag of several blog articles (e.g. `<main id="sf-main" tabindex="-1" id="sf-main" class="article-page" tabindex="-1">`). This is invalid HTML and can confuse screen readers or assistive technologies that rely on unique IDs and clean tab navigation structures.\n**Action:** Replaced instances of the duplicate attributes with a single `id` and `tabindex`.
