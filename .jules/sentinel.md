## 2026-09-08 - Path Traversal in Custom Static Server Middleware
**Vulnerability:** A critical path traversal vulnerability existed in the Express.js static file serving middleware in `server.js`. The server took the user-provided URL, decoded it, and passed it directly to `path.join(__dirname, urlPath)`.
**Learning:** `path.join()` resolves `..` segments relative to the base directory. If the incoming path is not validated against a root path *after* resolution, attackers can use URL-encoded `..` segments (like `%2f..%2f`) to escape the web root and read arbitrary system files (e.g., `/etc/passwd`).
**Prevention:** Always verify that the absolute path generated by `path.join()` or `path.resolve()` strictly starts with the intended root directory path (e.g., `filePath.startsWith(__dirname + path.sep)`) before accessing the file system. Consider using established static serving libraries (like `express.static`) where possible.
