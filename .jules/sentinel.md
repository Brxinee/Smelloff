## 2026-09-06 - Path Traversal in Custom Static File Middleware
**Vulnerability:** A path traversal vulnerability existed in the Express custom static file handling middleware (`server.js`). The code decoded `req.url` and joined it directly with `__dirname` using `path.join()`. This allowed an attacker to request paths containing encoded directory traversal sequences (`%2e%2e/%2e%2e`) and access arbitrary files outside the application root directory (e.g. `/etc/passwd`).
**Learning:** Custom static file handlers must always enforce strict boundaries. Even though Express's built-in `express.static()` protects against this, manually re-implementing static file serving without proper bounds checking can inadvertently open the server up to critical LFI (Local File Inclusion) vulnerabilities.
**Prevention:** Always normalize the final, resolved file path and ensure that it strictly starts with the intended base directory (`filePath.startsWith(__dirname)`) before serving the file. Consider relying on battle-tested middleware like `express.static` when possible.
